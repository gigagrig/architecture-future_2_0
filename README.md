## Статус эксплуатации

Workflow находятся в `.github/workflows`: проверки кода запускаются при push/PR, облачные plan/apply/destroy — вручную после настройки окружения. Права, зависимости и восстановление состояния описаны в README инфраструктуры. Значения секретов хранятся вне репозитория.
