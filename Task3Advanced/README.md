## Чтение схем

Тёмно-синий обозначает человека, серый — внешнюю систему, голубой — приложение или компонент, зелёный — защиту и аудит, фиолетовый — аналитику. Стрелка направлена от инициатора к получателю. Зелёные пунктирные связи обозначают проверки доступа и запись аудита, пунктирная рамка — границу системы на L2 или контейнера на L3.

![C4 L2: контейнеры платформы](diagrams/c4-containers.svg)

![C4 L3: компоненты API портала](diagrams/c4-components.svg)

Диаграммы описывают целевое состояние. Доменные обработчики и витрины представлены типовыми контейнерами: каждая команда владеет своими экземплярами, контрактами и правами. На L3 показаны связи, необходимые для проверки доступа и формирования отчётов; техническая телеметрия для каждого компонента опущена.
