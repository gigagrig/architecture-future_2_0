# Агрегаты и инварианты

Агрегат — граница одной согласованной транзакции; его корень управляет изменением состояния. Между агрегатами нет общей транзакции.

| Контекст / корень | Ключ и состав | Инварианты | Основные междоменные события |
| --- | --- | --- | --- |
| Registry / Patient | patient_id внутри клинического контура, регистрационный статус | Уникальность локальной идентичности; повтор registration_request_id не создаёт второго пациента | PatientRegistered |
| Care / Encounter | encounter_id, patient_ref, этапы визита, закрытые ссылки на записи | Нельзя завершить неоткрытый визит; медицинские записи не редактируются банковским контекстом | VisitCompleted |
| AI / ResearchJob | research_id, study_ref, model_version, статус, закрытый result_ref | Один результат на попытку; повторная обработка имеет отдельную attempt; статус Completed только при сохранённом результате | AIResearchCompleted |
| Billing / Invoice | invoice_id, billable_ref, денежные строки, валюта, статус | Сумма равна сумме строк; валюта едина; paid_amount не превышает total без отдельного процесса переплаты; settlement_id учитывается один раз | InvoiceIssued, InvoicePaid |
| Banking / LoanAgreement | agreement_id, банковский customer_ref, условия, статус | Только банковская идентичность; подписанный договор имеет неизменную версию условий; отмена явным переходом | LoanAgreementCreated |
| Banking / Payment | payment_id, invoice_ref, проводки/ссылки на ledger, статус | Уникальный idempotency_key; Settled только после подтверждённой проводки; повтор не создаёт второй платёж | PaymentSettled |
| Workforce / Capacity | clinic_id + день, число доступных слотов, версия расписания | Нельзя публиковать отрицательную мощность; изменение версии монотонно | StaffingCapacityChanged |
| Assets / Asset | asset_id, владелец, место, статус | Один действующий владелец; списанный актив нельзя повторно выдать без восстановления | — |
| Pharma / Batch | batch_id, supplier_ref, product_code, количество, срок годности | Количество неотрицательно; просроченная партия не выдаётся; receipt_id уникален | BatchReceived |
| Devices / Device | device_id, тип, статус, техническая версия | Статус меняется по допустимым переходам; диагностика устройства не равна диагнозу пациента | DeviceAvailabilityChanged |
| Analytics / DataProduct | product_id + major_version, owner, контракт, цели качества, классификация | Публикация требует владельца и разрешённой схемы; несовместимая схема получает новую major_version | — |
| Analytics / ReportDefinition | report_id, автор, product_refs, фильтры | Отчёт ссылается только на существующие версии; право сохранять определение не даёт права читать данные | — |
| Identity / AccessGrant | grant_id, сотрудник, scope, expiry | Ограниченный срок и явно заданная область; отзыв применяется при следующей проверке доступа | — |

Прочерк означает, что для агрегата не выделено междоменное событие в этой модели.

День в Capacity трактуется в часовой зоне клиники. Денежные величины передаются целыми минимальными единицами валюты, не floating point. Outbox сохраняется атомарно с изменением агрегата, содержит его версию. Конкурирующее изменение отклоняется optimistic locking по ожидаемой версии.

## Междоменные процессы

Счёт не считается оплаченным по одному лишь созданию кредитного договора. Billing ждёт `PaymentSettled`, сопоставляет invoice_ref и сумму, затем фиксирует оплату своей транзакцией. Неизвестная ссылка, валюта или частичная оплата отправляются в процесс сверки, а не автоматически закрывают счёт.

Patient и банковский Customer — разные модели. Расширение на фарму и устройства не создаёт общий агрегат «клиент со всеми данными».
