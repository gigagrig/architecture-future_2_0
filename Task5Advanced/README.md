## Пересчёт

Node.js 20 или новее; внешние пакеты и доступы не нужны:

```bash
node Task5Advanced/calculate-tco.mjs
node Task5Advanced/calculate-tco.mjs --help
```

Калькулятор читает JSON рядом с собой, проверяет размерность и неотрицательность сумм, рассчитывает базовое сравнение и два сценария чувствительности.
