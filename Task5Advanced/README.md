Технологический стек, сравнение стоимости текущей и целевой архитектуры и этапы внедрения Data Mesh. Экономические значения — сценарные допущения, а не тарифы поставщика или утверждённый бюджет.

## Пересчёт

Node.js 20 или новее; внешние пакеты и доступы не нужны:

```bash
node Task5Advanced/calculate-tco.mjs
node Task5Advanced/calculate-tco.mjs --help
```

Калькулятор читает JSON рядом с собой, проверяет размерность и неотрицательность сумм, рассчитывает базовое сравнение и два сценария чувствительности. Можно передать путь к другому JSON первым аргументом. Вывод — JSON в stdout, исходники не изменяются. Таблицы TCO соответствуют значениям из `tco-inputs.json`.
